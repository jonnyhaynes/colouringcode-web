## Editorial rule (governs every line)

> **Every claim carries a number or a concrete specific. Adjectives never do the work.**

"Award-winning", "leading", "world-class" — all cut on sight. If a sentence only works
because of the superhero metaphor, the sentence is wrong.

**Attribution rule:** work the team did before Colouring Code is *described, never named*,
and the "members of our team" framing is stated **once per section**, not per line.
